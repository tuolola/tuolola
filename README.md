## 关于我

我在做 **AI 辅助软件工程与 AI 编程工具**：连接需求、UML、测试与工程文档，也让电脑上的 AI 编程会话能在手机上继续。

我关注：**设计是否有来源、变更是否能追踪、生成结果是否便于检查和修改。**

- 🧩 **AI × 软件工程**：用模型辅助需求分析与设计，关联需求、模型和测试的来源。
- 💻 **跨端 AI 工具**：围绕 Web、Windows 与 Android，提供自托管、本地建模和移动端会话入口。
- 🛠️ **从原型到工具**：打磨交互、失败项重试、历史记录与文档导出，让工具更顺手。

## 主要项目

围绕 AI 辅助建模与 AI 编程，持续维护以下开源项目：

| 项目 | AI 应用方向 | 主要技术 |
| :--- | :--- | :--- |
| **[SoftJL Community](https://github.com/tuolola/SoftJL)** | 面向毕设与课程设计的自托管 AI 工作台，关联需求、UML、测试与 Word 工程文档，支持来源追踪与自带 OpenAI 兼容模型服务。 | TypeScript · React · Next.js · Fastify · PlantUML |
| **[SoftJL Desktop](https://github.com/tuolola/softJL-desktop)** | Windows 本地 AI 建模工作台，无需注册登录，支持对话建模、分阶段工程建模与 Word 导出；数据保存在本机，AI 调用使用自配模型服务。 | TypeScript · Electron · React · Fastify · Zod |
| **[CC Android Tunnel](https://github.com/tuolola/cc-android-tunnel)** | 连接自己的 CC Desk Tunnel 服务，在 Android 上延续 Claude Code 会话，查看流式回复、工具执行与历史，管理会话和模型设置。 | Kotlin · Jetpack Compose · WSS |

从梳理需求、检查设计，到在手机上继续编程，希望这些工具能融入实际的开发流程。

> CC Android Tunnel 基于 [sun168567/cc-desk-tunnel](https://github.com/sun168567/cc-desk-tunnel) 独立维护，是非官方 Android 原生移植，需配合上游服务端使用。

## 正在关注

- **需求追溯与变更影响**：定位需求关联的模型、测试与变更后需要复核的内容。
- **可检查的 AI 工作流**：展示任务状态与来源，支持失败项重试和结果修正。
- **模型服务接入**：打磨 OpenAI 兼容服务的配置、连接检查与实际用量展示。
- **工程产物交付**：衔接图表、测试用例与可编辑文档，方便后续检查、修改和说明。
- **移动端 AI 编程体验**：改善长会话阅读、流式输出、工具结果展示与断线恢复。

<summary>English introduction</summary>

I build AI-assisted software design and coding tools that connect requirements, UML models, tests and editable engineering documents, and make coding sessions accessible across devices.

My projects include **[SoftJL Community](https://github.com/tuolola/SoftJL)** for self-hosted web modeling, **[SoftJL Desktop](https://github.com/tuolola/softJL-desktop)** for local Windows modeling, and **[CC Android Tunnel](https://github.com/tuolola/cc-android-tunnel)** for continuing Claude Code sessions on Android. Both SoftJL editions support your own OpenAI-compatible model service. The Android client is an independently maintained, unofficial port based on [cc-desk-tunnel](https://github.com/sun168567/cc-desk-tunnel) and requires its server.

I focus on traceable designs, change impact analysis, inspectable AI workflows and practical mobile coding experiences.
